# Model weights (not committed to Git)

PyTorch checkpoints (`*.pt`) are **ignored by Git** (see the repo root `.gitignore`). Each developer must supply their own trained weights locally.

## Default path for development and Windows packaging

Place your trained checkpoint here:

```
backend/models/pcb_best.pt
```

The FastAPI backend, PyInstaller spec (`backend.spec`), and Electron installer (`extraResources`) all expect this filename for the bundled default model. The checkpoint is **not** downloaded or generated by the build.

## Using a different checkpoint

- **Development:** open **Model Manager** in the app and load any local `.pt` path.
- **Custom packaging:** copy your file to `backend/models/pcb_best.pt` before running `npm run dist:win`, or adjust `backend.spec` / `package.json` `extraResources` if you intentionally use another layout.

## Expected defect classes

The app is built for six PCB defect classes: `missing_hole`, `mouse_bite`, `open_circuit`, `short`, `spur`, `spurious_copper`. Your checkpoint should expose compatible class names (as trained in Ultralytics YOLO).
